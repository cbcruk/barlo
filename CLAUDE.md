# barlo

A Node.js port of GoogleChromeLabs/carlo: serve a web app from the runtime, open
it in a chrome-less Chrome window, and let the page call back into Node. No
bundled Chromium and no Puppeteer. See `README.md` for the architecture.

## Working on this repo

- Node 24+ runs the `.ts` source directly (type stripping), so keep relative
  imports suffixed with `.ts` and the syntax erasable — no enums, namespaces,
  or parameter properties.
- `npm test` needs a real display. On a headless box, run it under Xvfb:
  `xvfb-run -a --server-args="-screen 0 1280x1024x24" npm test`.
- Set `BARLO_CHROME_PATH` when there is no system Chrome; Playwright's browser
  cache works (`npx playwright install chromium`).
- `npm run typecheck` and `npm run docs:check` must pass before committing.
- `dist/` is generated by `npm run build` and is not committed; `prepack`
  rebuilds it when packing.
